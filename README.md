# lintglob

Lint URLs and glob query parts with stable normalization.

**Site:** https://theworker02.github.io/lintglob/

## Install / run

```bash
git clone https://github.com/theworker02/lintglob.git
cd lintglob
node src/cli.js
node --test
```
